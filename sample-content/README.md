# 샘플 덱

사이트에 함께 배포하는 유일한 질문으로, 지어낸 가짜 덱입니다. 시작 화면의 `샘플 덱으로 둘러보기`와 `#sample` 주소가 이 덱을 열고, 브라우저 검사는 내용이 바뀌지 않는 이 덱을 기준으로 돕니다. 개념과 답변은 모두 형식을 보여 주려고 지어낸 것이며 실제 지식이 아닙니다.

빌드는 이 폴더를 질문 파일 변환과 같은 규칙으로 읽습니다. 하위 폴더 하나가 분야 하나, 그 안의 마크다운 파일 하나가 질문 카드 하나입니다. 이 파일처럼 폴더 바로 아래에 있는 파일은 읽지 않습니다.

`tests/browser`가 이 덱의 질문 문구, 평가 항목 이름과 개수를 참조합니다. 카드 내용을 바꾸면 검사도 함께 고칩니다. 검사가 기대는 조건은 다음과 같습니다.

- `샘플 기초`: 카드 10장 이상. 연속 이동과 렌더링 범위 검사가 사용합니다
- `샘플 개념 01`: 평가 항목 5개와 `한 문장 정의` 항목
- `샘플 개념 02`: 덱에서 가장 긴 꼬리 질문이며 인라인 코드를 포함
- `샘플 비교 01`: 답변 C의 `바로잡을 부분`과 답이 비어 있는 첫 꼬리 질문
- `샘플 비교 03`: 덱에서 가장 긴 기초질문
