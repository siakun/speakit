# 샘플 비교 02

## 기초질문

> 샘플 비교 02에서 미리 준비하는 방식과 필요할 때 준비하는 방식은 언제 각각 유리한가요?

## 평가 체크리스트

- [ ] **미리 준비**: 미리 준비하는 방식이 유리한 상황을 말할 수 있는가?
  - 알아야 할 내용: 거의 확실히 쓸 값이고 첫 사용의 지연을 줄여야 할 때 유리합니다.
  - 빠뜨리면: 미리 준비하면 무엇을 얻나요?
- [ ] **필요할 때 준비**: 필요할 때 준비하는 방식이 유리한 상황을 말할 수 있는가?
  - 알아야 할 내용: 쓰지 않을 수도 있는 값이고 시작 시간을 줄여야 할 때 유리합니다.
  - 빠뜨리면: 필요할 때 준비하면 무엇을 얻나요?

## 1질문 3답변

### 답변 A: 원리형

> 미리 준비하면 첫 사용이 빠르고, 필요할 때 준비하면 시작이 빠릅니다.

- 키워드: 첫 사용, 시작
- 꼬리 질문: 말씀하신 첫 사용을 조금 더 여쭤보겠습니다. 어떤 값을 미리 준비하나요? -> **미리 준비**
- 놓친 항목: 없음

### 답변 B: 실무형

> 앱 시작이 느리다는 의견이 있어서 잘 쓰지 않는 기능을 필요할 때 불러오도록 바꿨습니다.

- 키워드: 앱 시작
- 꼬리 질문: 말씀하신 앱 시작을 조금 더 여쭤보겠습니다. 미리 불러온 기능도 남겼나요? -> **미리 준비**
- 놓친 항목: **미리 준비**

### 답변 C: 직관형

> 소풍 전날 도시락을 싸 두는 것과 아침에 싸는 것의 차이입니다.

- 키워드: 도시락
- 꼬리 질문: 말씀하신 도시락 비유를 조금 더 여쭤보겠습니다. 소풍이 취소될 수도 있다면 어느 쪽이 낫나요? -> **필요할 때 준비**
- 놓친 항목: **미리 준비**, **필요할 때 준비**(비유만 말함)

## 꼬리 질문

### 두 방식을 함께 쓸 수도 있나요?

자주 쓰는 값은 미리 준비하고 드물게 쓰는 값은 필요할 때 준비하도록 나눕니다.
