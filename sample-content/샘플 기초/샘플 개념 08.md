# 샘플 개념 08

## 기초질문

> 샘플 개념 08이 제대로 동작하는지 어떻게 확인하나요?

## 평가 체크리스트

- [ ] **확인할 동작**: 무엇을 확인해야 하는지 말할 수 있는가?
  - 알아야 할 내용: 정상 입력의 결과와 잘못된 입력에서 내는 오류를 모두 확인합니다.
  - 빠뜨리면: 정상 입력 말고 무엇을 더 확인하나요?
- [ ] **반복 가능성**: 확인을 다시 돌려도 같은 결과가 나오게 하는 방법을 말할 수 있는가?
  - 알아야 할 내용: 시간과 난수처럼 실행할 때마다 바뀌는 값을 고정합니다.
  - 빠뜨리면: 확인 결과가 가끔 달라지면 무엇을 의심하나요?

## 1질문 3답변

### 답변 A: 원리형

> 정상 입력과 잘못된 입력을 나눠 결과와 오류를 모두 확인합니다.

- 키워드: 잘못된 입력
- 꼬리 질문: 말씀하신 확인을 조금 더 여쭤보겠습니다. 결과가 가끔 달라지면 어떻게 하나요? -> **반복 가능성**
- 놓친 항목: **반복 가능성**

### 답변 B: 실무형

> 날짜가 바뀌는 자정에만 실패하는 확인이 있어서 시간을 고정했습니다.

- 키워드: 자정
- 꼬리 질문: 말씀하신 자정 실패를 조금 더 여쭤보겠습니다. 다른 입력은 무엇을 확인했나요? -> **확인할 동작**
- 놓친 항목: **확인할 동작**

### 답변 C: 직관형

> 요리를 맛보면서 간을 확인하는 것과 같습니다.

- 키워드: 맛보기
- 꼬리 질문: 말씀하신 맛보기를 조금 더 여쭤보겠습니다. 매번 같은 맛인지는 어떻게 아나요? -> **반복 가능성**
- 놓친 항목: **확인할 동작**, **반복 가능성**

## 꼬리 질문

### 확인을 자동으로 돌리면 무엇이 좋아지나요?

변경할 때마다 같은 기준으로 확인하므로 사람이 빠뜨리는 항목이 줄어듭니다.
