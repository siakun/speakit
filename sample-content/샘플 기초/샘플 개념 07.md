# 샘플 개념 07

## 기초질문

> 샘플 개념 07은 데이터가 늘어날수록 얼마나 느려지나요?

## 평가 체크리스트

- [ ] **증가 정도**: 데이터 크기에 따라 시간이 어떻게 늘어나는지 말할 수 있는가?
  - 알아야 할 내용: 데이터가 두 배가 되면 시간도 대략 두 배가 됩니다.
  - 빠뜨리면: 데이터가 두 배가 되면 시간은 얼마나 늘어나나요?
- [ ] **최악의 경우**: 가장 느려지는 입력을 말할 수 있는가?
  - 알아야 할 내용: 찾는 값이 맨 끝에 있거나 없을 때 모든 데이터를 확인합니다.
  - 빠뜨리면: 어떤 입력에서 가장 느려지나요?

## 1질문 3답변

### 답변 A: 원리형

> 처음부터 끝까지 한 번 훑으므로 데이터 크기에 비례해 느려집니다.

- 키워드: 한 번 훑기
- 꼬리 질문: 말씀하신 한 번 훑기를 조금 더 여쭤보겠습니다. 끝까지 훑는 경우는 언제인가요? -> **최악의 경우**
- 놓친 항목: **최악의 경우**

### 답변 B: 실무형

> 목록이 수천 개로 늘었을 때 검색이 눈에 띄게 느려졌습니다.

- 키워드: 수천 개
- 꼬리 질문: 말씀하신 수천 개를 조금 더 여쭤보겠습니다. 데이터가 두 배면 얼마나 느려졌나요? -> **증가 정도**
- 놓친 항목: **증가 정도**(체감만 말함), **최악의 경우**

### 답변 C: 직관형

> 책장을 왼쪽부터 한 권씩 확인하는 것과 같습니다.

- 키워드: 책장
- 꼬리 질문: 말씀하신 책장을 조금 더 여쭤보겠습니다. 찾는 책이 없으면 어떻게 되나요? -> **최악의 경우**
- 놓친 항목: **증가 정도**

## 꼬리 질문

### 더 빨리 찾으려면 무엇을 바꾸나요?

데이터를 미리 정렬하거나 찾는 값으로 바로 접근할 수 있는 구조에 담습니다.
