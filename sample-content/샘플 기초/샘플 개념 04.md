# 샘플 개념 04

## 기초질문

> 샘플 개념 04와 샘플 개념 03은 무엇이 다른가요?

## 평가 체크리스트

- [ ] **차이**: 두 개념이 다루는 대상의 차이를 말할 수 있는가?
  - 알아야 할 내용: 샘플 개념 03은 코드를 묶고, 샘플 개념 04는 데이터를 묶습니다.
  - 빠뜨리면: 두 개념은 각각 무엇을 묶나요?
- [ ] **함께 쓰기**: 두 개념을 함께 쓰는 경우를 예로 들 수 있는가?
  - 알아야 할 내용: 데이터를 묶은 뒤 그 데이터를 다루는 코드를 한곳에 둡니다.
  - 빠뜨리면: 두 개념을 함께 쓰는 예를 들어 주시겠어요?

## 1질문 3답변

### 답변 A: 원리형

> 샘플 개념 03은 코드를, 샘플 개념 04는 데이터를 묶는다는 점이 다릅니다.

- 키워드: 코드와 데이터
- 꼬리 질문: 말씀하신 코드와 데이터를 조금 더 여쭤보겠습니다. 둘을 함께 묶을 때는 언제인가요? -> **함께 쓰기**
- 놓친 항목: **함께 쓰기**

### 답변 B: 실무형

> 설정값을 샘플 개념 04로 묶고, 그 설정을 읽는 코드는 샘플 개념 03으로 모았습니다.

- 키워드: 설정값
- 꼬리 질문: 말씀하신 설정값을 조금 더 여쭤보겠습니다. 왜 데이터와 코드를 나눴나요? -> **차이**
- 놓친 항목: **차이**(사례만 말함)

### 답변 C: 직관형

> 하나는 상자이고 하나는 그 상자를 여는 열쇠입니다.

- 키워드: 상자와 열쇠
- 꼬리 질문: 말씀하신 상자와 열쇠를 조금 더 여쭤보겠습니다. 어느 쪽이 데이터인가요? -> **차이**
- 놓친 항목: **차이**, **함께 쓰기**

## 꼬리 질문

### 둘 중 하나만 써야 한다면 무엇을 고르나요?

바뀌는 쪽이 데이터라면 샘플 개념 04를, 바뀌는 쪽이 처리 방식이라면 샘플 개념 03을 고릅니다.
